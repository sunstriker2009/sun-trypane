# Changelog

## 0.1.0

- Embeddable TypeScript pane with host-owned input, run status, cancellation, and result rendering.
- C# Regex adapter with a .NET 10 WebAssembly worker, first and all matches, numbered and named captures, and a 100-match result limit.
- Versioned static bundle with a source commit manifest, compiled JavaScript, TypeScript declarations, and worker assets.
- Verified in Chromium, including a mobile viewport and the opt-in CodeFolio integration. The owner accepted a manual preview run and waived formal iPhone Safari acceptance.
